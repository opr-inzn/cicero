# Keyboard shortcuts

[Cicero Help](README.md) › Keyboard shortcuts

## Menus

| Shortcut | Command |
| --- | --- |
| ⌘, | **Cicero → Settings…** |
| ⌘O | **File → Add Fonts…** |
| ⇧⌘O | **File → Add Folder…** |
| ⇧⌘N | **File → New Set…** |
| ⌥⌘N | **File → New Smart Set…** |
| ⇧⌘E | **File → Export Fonts…** |
| ⌘↩ | **Fonts → Activate** |
| ⌥⌘↩ | **Fonts → Activate Temporarily** |
| ⌘⌫ | **Fonts → Deactivate** |
| ⌘Y | **Fonts → Quick Look** |
| ⌘↓ | **Fonts → Open** (one family selected) |
| ⌘I | **Fonts → Show Info** |
| ⇧⌘R | **Fonts → Reveal in Finder** |
| ⌥⌘C | **Fonts → Compare** (two or more families selected) |
| ⌥⌘T | **Fonts → Character Toolbox** |
| ⌘R | **Fonts → Rescan Library** |
| ⌘? | **Help → Cicero Help** |

While you type in a text field, like the search field, the sample text or a font page’s text, ⌘⌫ and ⌘ with an arrow key edit the text, as in any Mac app: ⌘⌫ deletes to the start of the line, and ⌘↓ moves to the end. They don’t deactivate or open fonts then. ⌘↩ and ⌥⌘↩ still activate the selected fonts.

## The browser

| Shortcut | Does |
| --- | --- |
| Click | Selects a family |
| ⌘-click | Adds a family to the selection, or takes it out |
| ⇧-click | Selects every family from the last one you clicked |
| ⌘A | Selects every family |
| Esc | Selects none |
| A letter or digit | Jumps to the first family starting with it |
| ↑ ↓ | Moves the selection; in the grid, a row of tiles |
| ← → | Moves the selection a tile, in the grid |
| ⇧ with an arrow key | Extends the selection, or shrinks it again |
| Space | Opens or closes Quick Look |
| ↩ or double-click | Opens the selected family’s font page |

## Quick Look

| Shortcut | Does |
| --- | --- |
| ↑ ↓ | Move the selection in the browser; the preview follows. In the grid, ← → do too |
| ← → | With several families selected, in the list and specimens: show the next or previous one, while the selection stays |
| ↩ | Opens the family’s font page |
| Space or Esc | Closes the preview |

## Font pages

| Shortcut | Does |
| --- | --- |
| Esc | Goes back to the browser |

## The sidebar

| Shortcut | Does |
| --- | --- |
| ⌘-click | Adds an item to the selection, or takes it out |
| ⇧-click | Selects every item from the last one you clicked |

## Character Toolbox

In the lists of families on both tabs:

| Shortcut | Does |
| --- | --- |
| ↑ ↓ | Moves the selection |
| ⇧↑ ⇧↓ | Extends the selection |
| ↩ or double-click | Opens the family in the main window |
| Esc | Selects none |

## Sheets

In sheets like the smart set editor, the character set editor and Clear Font Caches, ↩ clicks the blue button, like **Create**, **Save** or **Clear**.
