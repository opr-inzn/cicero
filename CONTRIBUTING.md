# Contributing

## Commit messages

One subject line, imperative, about the change a person would notice. The history already reads this way:

```
Fix text field focus when switching fonts
Ask before replacing fonts while InDesign is open
Drop Check Again from the Conflicts toolbar
```

That is usually the whole message. A body is only for a reason the diff doesn't show.

Leave out a subject that retells the diff, a long account of the thinking along the way, and vague lines like `Update files` or `Fixes`. No `feat:` prefixes or issue numbers; this log doesn't use them.

`git log` on `main` is the rest of it.
